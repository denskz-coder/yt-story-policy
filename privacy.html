Политика конфиденциальности приложения yt-story

Действует с 19 ноября 2026 года

1. Общие сведения

yt-story — личная служебная утилита, с помощью которой владелец канала загружает собственные готовые видеоролики на собственный канал YouTube. У приложения нет публичного веб-интерфейса, регистрации и доступа для третьих лиц; оно используется только владельцем канала и работает локально на его компьютере.

2. Какие данные обрабатываются

  • токен авторизации OAuth 2.0, выданный аккаунтом Google владельца канала;
  • видеофайлы, названия, описания, теги и обложки, которые владелец сам загружает на свой канал.

Приложение не собирает и не обрабатывает данные третьих лиц, не ведёт аналитику, не передаёт данные третьим лицам и не использует файлы cookie.

3. Использование сервисов YouTube API

Приложение использует YouTube API Services (YouTube Data API v3) с единственной областью доступа youtube.upload и вызывает только методы videos.insert (загрузка видео) и thumbnails.set (загрузка обложки). Данные канала через API не читаются.

Используя приложение, вы соглашаетесь с Условиями использования YouTube.

Политика конфиденциальности Google: https://policies.google.com/privacy.

4. Хранение и защита

Токен авторизации хранится локально на компьютере владельца канала в файле с ограниченным доступом и никогда не передаётся третьим лицам. Серверов у приложения нет.

5. Удаление данных и отзыв доступа

Доступ приложения к аккаунту Google можно отозвать в любой момент на странице myaccount.google.com/permissions или security.google.com/settings/security/permissions.

После отзыва доступа токен удаляется с компьютера владельца, и приложение теряет возможность обращаться к YouTube API. Загруженные видео остаются на канале и удаляются стандартными средствами YouTube Studio.

6. Контакты

Вопросы по обработке данных — через страницу канала на YouTube.

Privacy Policy (English summary)

yt-story is a private, locally run utility used by a single channel owner to upload his own videos to his own YouTube channel. It uses YouTube API Services with the single scope youtube.upload and only calls videos.insert and thumbnails.set. No third-party data is collected, no analytics, cookies or servers are used. The OAuth token is stored locally. By using this application you agree to be bound by the YouTube Terms of Service; Google's privacy practices are described at https://policies.google.com/privacy. Access can be revoked at myaccount.google.com/permissions, after which the local token is deleted.
