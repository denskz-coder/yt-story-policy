yt-story

Личная служебная утилита владельца канала для загрузки собственных видеороликов на YouTube.

YouTubeПубликация через YouTube Data API v3

Что делает утилита

Загружает заранее подготовленные видеоролики и обложки на собственный канал автора. Используются только методы videos.insert и thumbnails.set с областью доступа youtube.upload. Публичного интерфейса нет: утилита работает локально на компьютере владельца канала.
