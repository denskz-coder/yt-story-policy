Условия использования приложения yt-story

Действует с 19 ноября 2026 года

1. Назначение

yt-story — локальная утилита владельца канала для загрузки собственных видеороликов на свой канал YouTube через YouTube Data API v3.

2. Условия использования

Приложение предоставляется «как есть», без гарантий. Утилита использует YouTube API Services, поэтому её использование дополнительно регулируется Условиями использования YouTube и Политикой конфиденциальности Google.

Пользователь обязуется загружать только собственный контент, не нарушающий Правила сообщества YouTube и применимое законодательство.

3. Ответственность

4. Изменения

Условия могут обновляться; актуальная версия всегда доступна на этой странице.
